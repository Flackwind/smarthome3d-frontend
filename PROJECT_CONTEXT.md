# Smart Home 3D — context

Local self-hosted platform for a parametric home model and device control through Home Assistant.

Standalone frontend repository in `frontend/` under the shared SmartHome3D directory. Lightweight npm workspace: standalone Angular/Signals, strict TypeScript. Independent `home-model`, `geometry-engine`, and `device-model` packages. Providers do not know Three.js; the renderer receives only projects/normalized states. Optional independent sibling `backend/`: Java 21+/Spring Boot, JDBC, API v1; no frontend build dependency. Paths/commands here are frontend-relative unless stated otherwise.

Schema v1: building → floors → shared vertices, walls/openings, rooms referencing boundaries, furniture; separate entity bindings and scene settings. Meters, vertical elevation separate from the 2D plane. StorageService selects local IndexedDB or HttpProjectRepository over HTTP, with local non-sensitive preferences.

Direct connections keep HA credentials in tab memory only. Server mode since November 5, 2026 stores the HA refresh token encrypted in the backend owner profile, access token/verifier in RAM, and an HttpOnly browser cookie. Server sign-in derives the RAM key from the password and restores the last home/HA authorization after restarts. No browser credentials or credentials in home backups; HTTP sessions are not serialized. The user explicitly authorized this exception to the earlier RAM-only constraint. Offline mock available. Services/containers require explicit authorization.

MVP status: eight local-workflow milestones implemented, with explicit roadmap limitations. SVG editor discovers closed rooms, reuses walls, and edits vertices/openings/furniture. PNG/JPEG/first-page PDF are processed locally and calibrated. SceneController uses on-demand rendering, OrbitControls, and raycast; state changes update materials/lights without regenerating meshes. Self-contained GLBs are stored in IndexedDB. Wizard/dashboard/devices/settings cover creation, mapping, control, save, reopen, and backup.

HA provider: handshake, event-buffered snapshot, optional registries, per-entity capabilities, acknowledged commands, heartbeat, reconnect.
